Game life cycle

  1. Draft: a moderator creates the game; Game Defaults fill in the receiver, quit penalty and Player of the Day window.
  2. Open for Nomination: players join or are nominated. Pay-first players wait under Awaiting Payment until they pay. The share is ground cost ÷ max players.
  3. Game Started: set automatically at the start time.
  4. Completed: set automatically at the end time; the moderator can still tick who played and add late players. The share is re-split among the players who played.
  5. Nominate Player of the Day: open for the set window (24 hours by default), then the winner is announced.
  6. Archived: past games move to Archived; only an Admin can delete one.

Things to know

One database file

All data lives in one SQLite file on one Fly machine. It is cheap and simple, but backups are manual copies taken before each production deploy.

Payments in production

Cashfree is set up on staging only. Production tracks payments offline until Cashfree keys are added there.
